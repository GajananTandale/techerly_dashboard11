## Tcherly

### Installation Guide
> Please refer to [INSTALLATION.md](./INSTALLATION.md)

### Commands

Command | Description | Remarks
---|---|---
`yarn dev` | Starts the `development` servers | 
`yarn serve` | Starts the `production`  server |
`yarn deploy` | Used to deploy the code to production server |
`yarn generate` | Generate researcher user accounts | Use `yarn generate --help` to know more
